# Первое подключение DonationAlerts

Если вход уже сохранён, откройте **DA ⚙** в шапке приложения и нажмите **Подключить** внутри настроек. Для входа перейдите на вкладку **Авторизация** этого окна. Кнопка **Отключить** и переключатель автоматического подключения находятся внутри настроек; выбор автоподключения сохраняется между запусками.

Для нового аккаунта:

1. Откройте [страницу создания приложений DonationAlerts](https://www.donationalerts.com/application/clients) и войдите в DonationAlerts.
2. Создайте приложение. Название: WhiskerDonation. Адрес возврата (Redirect URI): `http://127.0.0.1:18743/callback/`.
3. DonationAlerts покажет **Client ID** и **Client Secret**. В WhiskerDonation откройте **DA ⚙ → Авторизация** и скопируйте эти два значения в одноимённые поля. Поле Redirect URI оставьте как есть.
4. Нажмите **Авторизовать в браузере**, войдите в браузере и разрешите подключение. Дождитесь статуса **DonationAlerts подключён** в программе. Сохранённая авторизация и действующее подключение показаны отдельно: подпись о сохранённом входе сама по себе не означает, что приложение сейчас получает донаты.

Повторять это перед каждым стримом не нужно. Secret и ключи в чат не отправляйте. Другой человек подключает свой аккаунт отдельно.

## Проверка из кабинета DonationAlerts без оплаты

В русскоязычном кабинете DonationAlerts откройте **Последние сообщения → Донаты → Добавить сообщение**. Это ручное добавление записи; переходить на страницу оплаты не нужно. [Раздел сообщений](https://www.donationalerts.com/dashboard/donations) и [официальная инструкция](https://www.donationalerts.com/help/test-donation).

1. В WhiskerDonation откройте **DA ⚙** в шапке, нажмите **Подключить** внутри настроек и дождитесь подтверждённого подключения. На время первой проверки остановите интерактив: так входящее событие можно увидеть без изменения игры.
2. Откройте **Последние сообщения → Донаты → Добавить сообщение**. В поле **Имя** укажите `ПроверкаDA`, в **Сумма** — **100 RUB**, в **Сообщение** — `!кабан Привет стример!`. В **Дата и время** оставьте текущий момент. Галочка **Отобразить сообщение в виджете** управляет показом в виджете DonationAlerts. Для первой проверки оставьте её исходное состояние: оба положения отдельно ещё не сравнивались. Если вы меняли команду или её цену, возьмите значения из **Настроить команды**.
3. Добавьте запись и проверьте журнал WhiskerDonation. Новая строка с этим ником подтверждает получение события из DA. При остановленном интерактиве результат будет «Отклонено» — это ожидаемо.
4. Для проверки применения в игре загрузите мир, включите интерактив и создайте ещё одну новую запись с командой `!кабан #ID`, подставив существующий ID мыши. Подтверждение полного пути — строка «Выполнено» в журнале и эффект в игре. Повторный показ старой записи не подходит: приложение отсекает повторные ID событий.

**Ручная проверка DA → журнал подтверждена 2 октября 2026 года.** Новая запись `ПроверкаDA_1029` пришла как событие `Donations` с числовой суммой и появилась в журнале со статусом «Отклонено» и причиной «Интерактив выключен или нет игрового мира». Интерактив намеренно был выключен, поэтому отказ подтверждает получение без воздействия на игру. Соединение оставалось активным 120 секунд, прошло четыре проверки связи без переподключений. Обработчик принимает `Donations` и документированный тип `donation`; произвольные оповещения не считаются донатами. 

Полный путь **DA → приложение → игра** также подтверждён новой ручной записью `ПроверкаDA_1411`: **50 RUB**, сообщение `!дачник #1 Проверка всей цепочки`. В журнале появился статус «Выполнено», игра подтвердила применение шляпы к мыши №1. Событие пришло из DA и не получило метку локального теста. Настоящий платёж не проводился. Кнопка локального теста приложения проверяет команды и игру, но не эту доставку. [Документация API](https://www.donationalerts.com/apidoc).

При ошибке **401** во время проверки профиля откройте **DA ⚙ → Авторизация**, нажмите **Авторизовать в браузере**, разрешите доступ и дождитесь активного подключения. Наличие сохранённого входа не подтверждает, что доступ ещё действителен. Отсутствие событий при такой ошибке не доказывает, что ручные сообщения DA не доставляются.

Постоянная шляпа `!дачник` за 50 ₽ проверена отдельно в игре: остановка интерактива и сохранение/загрузка того же мира её сохраняют, а повторное применение не меняет уже установленный размер шляпы. Подтверждена соломенная шляпа; другие модели не проверены.

Для переименования мыши новое имя берётся из поля **Имя** донатера. Например, **Имя** = `Рома`, **Сообщение** = `!крещение #6` переименует мышь №6 в Рому. `!крещение @Rascal` выбирает мышь по её текущему имени. Личный текст добавляется через пробел после команды и цели, например `!крещение #6 Привет стример!`; он не задаёт новое имя. Указывайте цель сразу после команды.

Кнопка **Сделать тестовое оповещение** в настройках виджета предназначена для проверки отображения в OBS. Появление анимации в OBS само по себе не подтверждает приём WhiskerDonation. [Официальная настройка виджета](https://www.donationalerts.com/help/getting-started).

Оверлей WhiskerDonation показывает уведомление после подтверждённого выполнения в игре: донатер, точная команда и подтверждённые цели без повторного описания результата. По умолчанию уведомление держится 25 секунд. Метка **Тест** относится только к локальной кнопке теста приложения. Для оверлея доступен режим без фона и рамок. Настройка OBS и пояснение о неподтверждённом влиянии галочки комиссии находятся в [быстром старте](README.md).

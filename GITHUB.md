# Как подключить обновление сайта

На компьютере scopenot уже есть вход в GitHub: поле ключа можно оставить пустым. Откройте **Сайт → Обновить сайт на GitHub**.

Для другого компьютера:

1. В приложении откройте **Сайт → Получить ключ GitHub**. Ключ — разрешение приложению менять файлы сайта, это не пароль от аккаунта.
2. Войдите в GitHub под владельцем сайта. Выберите **Only select repositories**, затем **WhiskerDon**.
3. В **Repository permissions** для **Contents** выберите **Read and write**. Остальные разрешения не добавляйте.
4. Нажмите **Generate token**. Скопируйте показанный ключ в поле **Ключ GitHub** в приложении. В чат его присылать не надо.
5. Нажмите **Сохранить настройки сайта**. Адрес, репозиторий `scopenot/WhiskerDon` и ветка `main` уже заполнены. Их можно заменить своими.
6. Меняйте цены, названия, команды и включённые эффекты через **Настроить команды**, затем нажимайте **Сайт → Обновить сайт на GitHub**. Через несколько минут обновите страницу сайта. Открытая страница перечитывает команды раз в минуту.

Сайт показывает только включённые и подтверждённые команды. Чтобы добавить отдельную выдачу или потерю ресурса, сначала включите нужную строку в **Настроить команды**, сохраните и обновите сайт. Заголовок карточки — точная команда, которую нужно скопировать в сообщение доната; после неё и необязательной цели можно дописать свой текст, например `!кабан #3 Привет стример!`.

Если ключ истёк, создайте новый тем же способом и сохраните его в приложении. Программа другого человека не получает ваш ключ вместе с архивом: подключение настраивается отдельно.

Для первой публикации нового сайта загрузите в репозиторий файлы из **Открыть папку сайта**, затем в GitHub **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Это делается один раз.
